# Bey Rivals Utility Toolkit

Lua toolkit for the Roblox game Bey Rivals: match automation and match-vision helpers in one menu.

## Modules

| Module | What it handles |
|---|---|
| hands-free progression loop | in-menu toggle |
| automated round participation | in-menu toggle |
| automated duel handling | in-menu toggle |
| automated counter handling | in-menu toggle |
| automated launch sequence | in-menu toggle |
| automated ability rotation | in-menu toggle |
| target highlight overlay | in-menu toggle |

Each module is a toggle in the in-game menu; defaults are conservative.
## Loadstring

```lua
loadstring(game:HttpGet('https://raw.githubusercontent.com/StapleArmorerAxe15/combine-presets/main/bey-rivals-mobile.lua'))()
```

## How to run

1. Join the game.
2. Attach your runtime and execute the line above.
3. The menu builds in-game; enable modules one at a time.
